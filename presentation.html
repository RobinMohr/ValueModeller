Challenge & Approach

The Challenge
We started with an Excel template for value stream data capture, but spreadsheets have big limitations:
• Difficult to visualize non-linear processes — and we have lots of them
• Freeform text entry means the same teams, applications, and processes get called by many different names
• After capturing information, we want to query it in a structured database without exporting again and again
Our Approach
Working interactively with Kiro, we went for a canvas-based approach where the individual process steps can be linked with drag and drop in an intuitive view. Structured form inputs enforce consistency across teams and applications.

Results & Next Steps

What Worked
A fully functional value stream editor with drag-and-drop canvas, branching/merging flows, structured SIPOC forms, auto-save, undo/redo, import/export — built in 2 days with Kiro.
Next Steps
  • Connect to a real backend database so captured value streams can be queried structurally — no more re-exporting from spreadsheets
  • Add real-time collaboration so multiple product owners can map value streams together
